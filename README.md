## 1. Course Description

The NXG Python Foundation Course is a practical software development learning program designed to develop fundamental Python programming skills through hands-on exercises and engineering projects.

The course focuses on problem-solving, logical thinking, application development, testing, documentation, and professional software development practices.

Throughout the course, I will complete 12 practical engineering projects covering real-world scenarios in education, healthcare, finance, business, and information management.

All project data will be fictional and used for educational purposes.

## 2. Learning Objectives

By completing this course, I aim to:

1. Understand Python programming fundamentals.
2. Use variables, data types, and operators.
3. Apply conditional statements to solve problems.
4. Work with Python data structures.
5. Process lists and collections of information.
6. Develop practical command-line applications.
7. Perform calculations using Python.
8. Write and execute software tests.
9. Document software applications professionally.
10. Use Git and GitHub for version control and project management.
