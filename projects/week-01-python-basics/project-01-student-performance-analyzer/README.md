## Student Information Display System
# Introduction
This is my first Python project, developed as part of the Python Foundation course. The purpose of this project is to practice basic Python programming by creating a simple program that displays student information.
In this project, I used Python variables to store student information such as name, student ID, age, gender, department, course, city, and enrollment year. I also used the print() function to display the information on the screen in a clear and organized way.
What I Learned
Through this project, I learned how to create variables, assign values, and use different data types such as strings and integers. I also practiced using the print() function to display information.
This project helped me understand the basics of Python and gave me confidence to start learning more programming concepts.
